1. Executive Summary

What We Built

A self-service tax quote builder that allows prospects to get instant price quotes for tax preparation services 24/7, directly from the Tavola Group website.

Key Benefits

Benefit Impact
24/7 Lead CaptureNever miss a potential client
Instant QuotesNo waiting for callbacks
Automated Follow-upRecover abandoned leads
CRM IntegrationSeamless lead management
Rate LimitingPrevent spam/abuse

Results

  • Prospects can get quotes in under 5 minutes
  • Leads captured even from incomplete submissions
  • Automatic follow-up sequence for abandoned forms
  • Direct sync to HubSpot CRM

2. Project Overview

The Problem

Tavola Group needed a way to:

  • Provide instant tax quote estimates to website visitors
  • Capture leads around the clock
  • Follow up with prospects who don't complete the form
  • Reduce manual work for the team

The Solution

A WordPress plugin with:

5-Step Wizard

Guided questionnaire with real-time preview

Price Calculation

Instant quotes based on services selected

Email Automation

Follow-up sequence for abandoned leads

HubSpot CRM

Automatic contact and deal creation

System Requirements

3. How It Works

The 5-Step Wizard

┌─────────────────────────────────────────────────────────────────────┐ │ │ │ STEP 1 STEP 2 STEP 3 │ │ ┌────────────┐ ┌────────────┐ ┌────────────┐ │ │ │ Select │ → │ Contact │ → │ Filing │ │ │ │ Return │ │ Info │ │ Details │ │ │ │ Type │ │ │ │ │ │ │ └────────────┘ └────────────┘ └────────────┘ │ │ │ │ STEP 4 STEP 5 │ │ ┌────────────┐ ┌────────────┐ │ │ │ Review │ → │ Result │ │ │ │ │ │ │ │ │ └────────────┘ └────────────┘ │ │ │ └─────────────────────────────────────────────────────────────────────┘

Step Details

Step 1: Return Type Selection

  • Individual tax return
  • Business tax return (C-Corp, S-Corp, Partnership)
  • Can select both for combined quote

Step 2: Contact Information

  • Name, Email, Phone
  • Data saved as "in_progress" partial

Step 3: Filing Details

  • Dynamic questions based on selected type
  • Real-time price preview

Step 4: Review

  • Summary of all answers
  • Final price estimate
  • Edit capability

Step 5: Result

  • Calculated quote or "Custom Quote Required"
  • Email confirmation sent
  • Option to schedule a call

Business Return Pricing

Formula

Total = Base Fee (Part A) + Extras (Part B)

Part A: Base Fee Calculation

Step 1: Check Asset Level ├── $5M-$10M → Custom Quote └── Over $10M → Custom Quote Step 2: Check Schedule L Requirement ├── If NOT required → $999 flat └── If required → Go to Step 3 Step 3: Calculate from Asset Band + Revenue └── Base Price + Revenue Add-on (if >$1M)

Status Transitions

┌─────────────────┐ │ Form Loaded │ │ (No Status) │ └────────┬────────┘ │ │ Contact info entered ▼ ┌─────────────────┐ ┌──────────│ in_progress │──────────┐ │ └─────────────────┘ │ │ │ │ Complete Click │ Submit Start ▼ ▼ ┌─────────────────┐ ┌─────────────────┐ │ completed │ │ abandoned │ │ │ │ │ └─────────────────┘ └─────────────────┘ ▲ ▲ │ 1 week │ cron │ │ └────────────────────────────────────────┘ (auto-abandoned if still in_progress)

Abandoned Record Protection

Once a record is marked abandoned:

  • Cannot be updated accidentally
  • Excluded from IP conflict checks
  • No follow-up emails sent
  • Preserved for reporting purposes

13. FAQ

For Clients

Q: How long does it take to get a quote?

A: Under 5 minutes for most users.

Q: What if my situation is complicated?

A: If you need a custom quote, you'll be directed to schedule a call.

Q: What happens if I don't finish the form?

A: You'll receive reminder emails unless you click "Start Over."

Q: Can I quote both personal and business taxes?

A: Yes, you can select both and get a combined quote.

For Developers

Q: How do I add a new Individual service?

A: Go to Quote Builder → Individual Tab → Add New Item.

Q: How do I change the HubSpot pipeline?

A: Update in HubSpot settings; deal creation code is in class-tqb-hubspot.php.

Q: Where are the email templates?

A: In class-tqb-email.php as static methods.

Q: How do I test locally?

A: Use XAMPP/MAMP; IP will show as 127.0.0.1 or ::1.
