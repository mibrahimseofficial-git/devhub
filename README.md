# Tavola Quote Builder Plugin

WordPress plugin for tavola.group - Self-service pricing questionnaire for Individual and Business tax return quotes.

## Installation

1. Download the latest release or clone the repository
2. Upload the  folder to 
3. Activate the plugin through the WordPress admin
4. Configure settings in WordPress Admin > Quote Builder

## Features

- Self-service pricing questionnaire
- Individual and Business tax return quotes
- Real-time price calculation
- Admin dashboard for pricing management
- Email notifications
- HubSpot integration
